# iyi-markd

Port in progress of [markd](https://github.com/icyleaf/markd) 0.5.0,
commit `d61dd52d40e659b53cb78712a7b1190cfdb9bc66`.

The parser and renderer are generated migration output and still depend on
Crystal. The node, options, and entity decoding modules are being ported to
iyi's native library. This package is not ready for use or release.
